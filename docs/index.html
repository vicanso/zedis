Native & fast

Virtual-scrolled SCAN, million-key trees, light / dark / system plus 6 bundled themes — macOS, Windows, Linux.

🧠

Smart viewers

Auto-decompress LZ4/Snappy/GZIP/ZSTD. JSONPath, Protobuf, timestamps, images, custom script viewers.

📊

Observability

Live metrics + 7-day history, memory analyzer (live or offline RDB), Slow Log, MONITOR, raw INFO, cluster tools.

🔑

Keys & bulk ops

Namespace tree, tags, recycle bin, Tools export with prefix filter (binary / JSON / CSV), cross-server copy & diff.

🔐

Privacy-first

Per-machine encrypted secrets, ACL editor, tags & history kept in a local file. No accounts, no telemetry.

🧭

Works on limited servers

Capability probe on connect: proxies, ElastiCache / Azure / Tair, Valkey / Dragonfly / KeyDB grey out what they can’t run — with the reason — instead of erroring.

🔌

Connect anything

TLS/SSL, SSH tunnels, Cluster & Sentinel. Staged DNS → TCP → TLS → AUTH diagnostics, and a link that reconnects itself through a failover.

⌨️

Power-user UX

⌘K palette, ⌘P recent keys, ⌘⇧F multi-db search, redis-cli + ? AI assistant, batch mode.

Install

Latest release v0.8.3 — package managers or binaries from GitHub Releases.

macOS

brew install --cask zedis

Or grab a .dmg (Apple Silicon / Intel) from Releases.

Windows

scoop bucket add extras && scoop install zedis

Or download .msi / .zip from Releases.

Linux

yay -S zedis-bin

Or use .deb / .rpm / AppImage / tarball from Releases (x86_64 and aarch64).

From source

cargo install --git https://github.com/vicanso/zedis --locked zedis-gui

crates.io may lag (GPUI is a git dependency). Prefer git or Releases.
