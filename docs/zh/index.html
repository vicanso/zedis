安装

最新版本 v0.8.3——包管理器，或从 GitHub Releases 下载二进制。

macOS

brew install --cask zedis

或从 Releases 下载 .dmg （Apple Silicon / Intel）。

Windows

scoop bucket add extras && scoop install zedis

或从 Releases 下载 .msi / .zip。

Linux

yay -S zedis-bin

或从 Releases 使用 .deb / .rpm / AppImage / tarball（x86_64 与 aarch64）。

源码安装

cargo install --git https://github.com/vicanso/zedis --locked zedis-gui

crates.io 可能滞后（GPUI 为 git 依赖）。推荐 git 或 Releases。
