# Zedis UI

Reusable GPUI widgets for [Zedis](https://github.com/vicanso/zedis): `ZedisCard`, `ZedisDialog`, `ZedisForm`, `ZedisTextTable` (the one read-only text grid its observability panels share) and a few smaller pieces. Target-agnostic — the same code builds for the desktop and the browser — and free of the app's helpers and translations: fonts and localized strings are passed in by the caller.

Part of the Zedis workspace — see the [repository root](https://github.com/vicanso/zedis) for build and contribution docs.
