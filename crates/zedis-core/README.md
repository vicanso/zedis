# zedis-core

GUI-free pure logic shared by [Zedis](https://github.com/vicanso/zedis): the `Capability` permission matrix and the server feature matrix, the value decoders, an RDB file parser, fuzzy matching, key-tree segmentation, hex/CSV/diff helpers, JSONPath utilities, TTL formatting, `~/.ssh/config` parsing, and filesystem/env helpers. No gpui, no i18n.

Part of the Zedis workspace — see the [repository root](https://github.com/vicanso/zedis) for build and contribution docs.
